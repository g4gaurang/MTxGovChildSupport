# MTX Gov Child Support

A responsive product-positioning prototype for MTX Gov Child Support.

## Content notes

- Product capabilities describe the intended product scope and positioning.
- The FY 2024 national child support figures and five federal program measures are sourced from the U.S. Administration for Children and Families, Office of Child Support Services preliminary report.
- The prototype does not present national program figures, illustrative dashboard values or recommended operational indicators as MTX client outcomes.

## Run locally

Open `index.html` directly, or serve the directory with any static web server.

## GitHub Pages

The included workflow publishes the repository root as a static site through GitHub Pages.
